# 로그인 브랜드 자산

2026-09-30 각 제공자 공식 자료에서 가져온 원본. 로고 비율/색상 유지. OAuth는 미설정 상태임을 화면에서 표시한다.

- Google: https://developers.google.com/identity/branding-guidelines — https://developers.google.com/static/identity/images/g-logo.png
- Kakao: https://developers.kakao.com/docs/ko/kakaologin/design-guide — https://developers.kakao.com/tool/images/resource/preview/login-simple-ko.svg
- Naver: https://developers.naver.com/docs/login/bi/bi.md — 공식 NAVER_login_KR.zip의 NAVER_login_Light_KR_green_icon_H48.png
- Apple: https://developer.apple.com/documentation/signinwithapple/displaying-sign-in-with-apple-buttons-on-the-web — https://appleid.cdn-apple.com/appleid/button/logo (black, 40×40 요청, 원본 이미지 30×30)

각 브랜드의 상표 및 사용 가이드가 적용된다. 외부 CDN 호출 없이 프로젝트 static에서 제공한다.
